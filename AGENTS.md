# Работа по веткам

Каждый участник начинает со стартового коммита в `main` и ведёт работу в своей ветке. Названия владельцев ниже обозначают роли. Команда назначает участников на эти роли.

| Ветка | Владелец | Файлы и минимальный результат |
| --- | --- | --- |
| `feature/core` | Агент Core | `src/core/`. Размещение и удаление, буферы, рецепты, конвейеры и продажа в симуляции |
| `feature/world` | Агент World | `src/world/`. Карта, персонаж, выбор клетки, предпросмотр и отправка команд |
| `feature/art` | Агент Art | `src/art/`, `public/assets/`. Визуалы игрока, цветов, зданий и конвейеров через `FactoryArt` |
| `feature/gameplay` | Агент Gameplay и интеграции | `src/ui/`, `src/config/`. Хотбар, HUD, цены, параметры рецептов и сборка демо |

```sh
git clone https://github.com/akchernov/factory.git
cd factory
git switch -c feature/core
npm ci
```

Подставьте свою ветку вместо `feature/core`. Если ветка уже опубликована, переключитесь на неё через `git switch --track origin/feature/core`.

## Интеграция

1. Core и World работают через `FactorySimulation`. Art сохраняет сигнатуры `FactoryArt`. Gameplay согласует с World хотбар, а с Core — формат цен и рецептов.
2. Изменения в `src/shared/` и `src/main.ts` координирует владелец интеграции. Сообщите ему о нужной правке до изменения публичного контракта. Входные точки `createSimulation`, `createArt`, `createHud` и `FactoryScene` сохраняют совместимость с основанием.
3. Перед отправкой ветки выполните `npm run build` и откройте игру локально. В PR укажите, какой сценарий проверили и какие зависимости от других веток появились.
4. Владелец интеграции объединяет ветки в `main`, проверяет сборку и проходит сценарий продажи первой банки.
