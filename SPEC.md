# Bee Factory — спецификация хакатона

Игрок ходит по карте, строит линию производства мёда и продаёт первую банку. Игра целиком работает в браузере.

## Цепочка для демо

| Этап | Поведение MVP |
| --- | --- |
| Цветы → улей | Улей рядом с цветочной клеткой получает нектар и даёт соты |
| Улей → конвейеры | Соты идут к медогонке по цепочке направленных конвейеров |
| Медогонка | Соты превращаются в мёд |
| Фасовка | Мёд превращается в банки |
| Продажа | Рынок принимает банки и увеличивает баланс |

Для двухчасового демо достаточно одной рабочей линии. Игрок выбирает здание в хотбаре, поворачивает его и ставит на свободную клетку. HUD показывает ресурсы и монеты. Минимальный критерий демо — игрок собирает линию и видит рост баланса после продажи. Цены, интервалы и клавиши строительства согласуют Core, World и Gameplay.

## Координаты и время

- `GridPosition` хранит целые `col` и `row` от нуля. Колонки идут вправо, строки вниз.
- `WorldPosition` хранит `x` и `y` в пикселях от верхнего левого угла карты. `tileCenter` даёт центр клетки, `worldToTile` переводит точку в клетку без подрезки по границам. Для проверки границ используйте `isInGrid`.
- Размер стартовой карты — 24 × 15 клеток по 32 px. Направления `north/east/south/west` соответствуют вверх/вправо/вниз/влево.
- Phaser передаёт время кадра в миллисекундах. Сцена передаёт в движение секунды и использует скорость в px/с. Симуляция получает вызов `step()` за каждые 100 мс накопленного времени. Один кадр учитывает до 250 мс, чтобы не прокручивать игру после паузы.
- Длительности рецептов и перемещений внутри симуляции задаются в целых тиках. `snapshot.tick` начинается с нуля. Количество ресурсов и монеты — целые единицы.

## Контракты модулей

- `createSimulation(grid)` возвращает `FactorySimulation`. Core владеет состоянием производства, буферами, балансом и проверкой команд. Модуль работает без Phaser и DOM.
- `dispatch({ type: 'place', kind, tile, facing })` и `dispatch({ type: 'remove', tile })` применяют команду синхронно. При отказе состояние остаётся прежним. `getSnapshot()` возвращает доступное только для чтения состояние после последней команды или тика. `inventory` на здании описывает его буфер, `inventory` на фабрике — отдельный запас игрока.
- World передаёт команды из управления, вызывает `step()` по таймеру и обновляет представление по снимку. После успешной команды World может сразу перечитать снимок.
- `FactoryArt` предоставляет `preload`, `createPlayer`, `drawFlower` и `syncBuildings`. `syncBuildings` принимает полный список зданий. Art обновляет существующие объекты по `id` и удаляет отсутствующие, чтобы повторный вызов не дублировал объекты.
- `FactoryHud.render(snapshot)` отображает состояние. Gameplay подключает управление хотбаром через согласованный с World интерфейс.
- Ресурсы в коде — `nectar`, `comb`, `honey`, `jar`. Здания — `hive`, `conveyor`, `extractor`, `packer`, `market`.

Стартовый коммит реализует движение, таймер, снимок с тестовыми цветами, круги-заглушки и HUD. Строительство возвращает `not-implemented` для клеток внутри карты. Производство, транспорт и продажа входят в задачи веток.
