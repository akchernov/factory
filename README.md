# Bee Factory

Браузерная top-down игра про медовую фабрику. Стартовая сцена показывает сетку, цветы, персонажа и счётчики. Управление — **WASD** или **стрелки**.

## Запуск

Нужен Node.js 20.19+ в ветке 20.x или Node.js 22.12+.

```sh
npm ci
npm run dev
```

Откройте адрес из терминала. Для проверки перед PR выполните `npm run build`. Команда проверяет типы и собирает статические файлы в `dist/`. Чтобы открыть собранную версию локально, выполните `npm run preview`.

## Где работать

| Путь | Назначение |
| --- | --- |
| `src/shared/` | Типы, команды симуляции и преобразование координат |
| `src/core/` | Симуляция фабрики |
| `src/world/` | Сцена Phaser, карта и управление |
| `src/art/`, `public/assets/` | Отрисовка и игровые ассеты |
| `src/ui/`, `src/config/` | HUD и настройки игры |
| `src/main.ts` | Подключение модулей |

[SPEC.md](SPEC.md) описывает цель демо и контракты. [AGENTS.md](AGENTS.md) распределяет работу по веткам.
