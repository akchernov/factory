# Bee Factory

Браузерная top-down игра про медовую фабрику. Карта с рекой, мостами, лесом и скалами генерируется по числу в параметре `seed`. Откройте адрес с тем же числом, чтобы получить тот же ландшафт, или уберите параметр для новой карты.

## Управление

- **WASD** или **стрелки** — ходьба. **C** возвращает камеру к персонажу.
- **Колесо мыши** приближает карту к курсору. **Средняя кнопка** или **пробел + ЛКМ** перетаскивают карту.
- **1–5** выбирают постройку, **ЛКМ** ставит её. **R** или **ПКМ** поворачивают постройку под курсором или эскиз на свободной клетке.
- **X** или **«Продать»** включает режим продажи. Щёлкните по своей постройке или нажмите **Delete** над ней. Монеты возвращаются, содержимое переносится в инвентарь. **Esc** или выбор инструмента выключает режим.
- Кнопка **«На весь экран»** разворачивает игру, **Esc** возвращает в окно.

## Запуск

Нужен Node.js 20.19+ в ветке 20.x или Node.js 22.12+.

```sh
npm ci
npm run dev
```

Откройте адрес из терминала. Для проверки перед PR выполните `npm run build`. Команда проверяет типы и собирает статические файлы в `dist/`. Чтобы открыть собранную версию локально, выполните `npm run preview`.

## Где работать

| Путь | Назначение |
| --- | --- |
| `src/shared/` | Типы, команды симуляции и преобразование координат |
| `src/core/` | Симуляция фабрики |
| `src/world/` | Сцена Phaser, карта и управление |
| `src/art/`, `public/assets/` | Отрисовка и игровые ассеты |
| `src/ui/`, `src/config/` | HUD и настройки игры |
| `src/main.ts` | Подключение модулей |

[SPEC.md](SPEC.md) описывает цель демо и контракты. [AGENTS.md](AGENTS.md) распределяет работу по веткам.
