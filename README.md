# Bee Factory

Браузерная игра про медовую фабрику в духе Factorio: ульи, конвейеры, станки, наука, селекция пчёл и оборона от медведей и шершней. Ветка `rewrite` это полная переработка стартового каркаса.

## Запуск

Нужен Node.js 20.19+ в ветке 20.x или Node.js 22.12+.

```sh
npm ci
npm run dev      # разработка
npm run build    # проверка типов и сборка в dist/
npm test         # тесты симуляции, боёв, обучения и баланса
npm run balance -- 8 30 smart   # бот проходит игру: число карт, лимит дней, режим (smart, short, lazy, nodefense, peaceful)
```

`dist/` после сборки это обычная статика, её можно отдать любым сервером или задеплоить на Vercel (framework: Vite).

## Управление

| Действие | Клавиши |
| --- | --- |
| Выбрать здание | цифры и буквы на хотбаре |
| Поставить, тянуть конвейер или забор | ЛКМ |
| Снести | ПКМ или Del |
| Повернуть | R (на русской раскладке К) |
| Камера | WASD, перетаскивание, колесо мыши |
| Пауза | Space |
| Наука, пчёлы | T, B |
| Срубить дерево или камень | клик по нему (5 монет) |

## Что есть в игре

- Цепочки: соты, мёд, воск, банки, свечи, медовуха.
- 17 зданий, дерево из 10 технологий, рынок с плавающими ценами.
- Селекция: 8 видов пчёл, мутации, редкие продукты (пыльца, прополис, маточное молочко).
- Враги: медведи вечером, шершни днём из гнёзд. Оборона: дымари (топливо воск) и заборы. Есть мирный режим.
- Два режима: «Быстрая партия» (8 заданий, около 10 минут, для показа) и «Полная игра» (14 заданий, финал: построить и наполнить Великий улей).
- Панель исследования показывает, сколько ресурса приходит в минуту и сколько ждать.
- День и ночь, мини-карта, автосохранение в браузере.

## Структура

| Путь | Назначение |
| --- | --- |
| `src/core/data.ts` | Весь баланс и данные: предметы, здания, рецепты, пчёлы, технологии, враги, задания |
| `src/core/sim.ts` | Симуляция без Phaser и DOM, детерминированная (тик 100 мс) |
| `src/core/map.ts`, `rng.ts` | Генерация карты по сиду |
| `src/game/WorldScene.ts` | Сцена Phaser: мир, ввод, отрисовка зданий, пчёл и врагов |
| `src/game/ui.ts`, `src/style.css` | Интерфейс на DOM: топбар, хотбар, задания, инспектор, окна |
| `src/game/audio.ts` | Процедурный звук и музыка, без файлов |
| `src/game/textures.ts` | Конвейеры и эффекты, нарисованные кодом |
| `public/assets/` | Спрайты (webp) |
| `tools/slice.py` | Нарезка листов спрайтов с пурпурного фона |
| `tools/bot.ts`, `tools/balance.ts` | Бот, который проходит игру через API симуляции, и отчёт по балансу |
| `tests/` | Тесты симуляции, боёв, обучения и баланса |

Баланс правится только в `src/core/data.ts`.
